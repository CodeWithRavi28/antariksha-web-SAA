# 🚀 SLIET Antariksha Vigyan Club

A modern, responsive, and premium website for the **SLIET Antariksha Vigyan Club**, designed to inspire students to explore astronomy, astrophysics, and space technology.

## ✨ Features

- 🌌 Modern Landing Page
- 📖 About the Club
- 🛰️ Domains of Exploration
- 📅 Events Timeline
- 👥 Team Showcase
- 📩 Join Club & Contact
- 📱 Fully Responsive
- ⚡ Smooth Animations
- ♿ Accessible Design

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
